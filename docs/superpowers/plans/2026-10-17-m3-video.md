# M3 "Video settings and light" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Video settings (window, render scale, frame rate, ambient occlusion, shadows, anti-aliasing, brightness/contrast/gamma) in a settings screen saved to a file, lighter shadows, and a sun that follows Crossfire's game clock.

**Architecture:** Pure, tested modules in the `maccrossfire` lib: `settings.rs` (model, file, allowed combinations) and `clock.rs` (parse the server's `time` reply, advance by ticks, sun pose per hour); `modes.rs` gains `Mode::Settings`. Thin Bevy code applies settings (`graphics.rs`), moves the sun (`world.rs`), and draws the screen (`settings_ui.rs`), checked by screenshot.

**Tech Stack:** Rust stable, Bevy 0.20 (`ScreenSpaceAmbientOcclusion`, `TemporalAntiAliasing`, `Msaa`, `ColorGrading`, `DirectionalLightShadowMap`, `CascadeShadowConfig`, `Window`/`WindowMode`/`PresentMode`), bevy_egui 0.43.

**Spec:** `docs/superpowers/specs/2026-10-17-m3-video-design.md`

## Global Constraints

- GPLv2+. Mac first. Works on Crossfire 1.75.0+. Only new client→server traffic: one `time` command per login.
- Settings file: `$HOME/Library/Application Support/MacCrossfire/settings.txt`, `key=value` lines. Missing/broken file → defaults; bad line skipped; never a crash.
- Never apply MSAA together with ambient occlusion (Bevy limit): `Settings::normalized()` turns MSAA into TAA when AO is on.
- Crossfire clock (`include/tod.h`, `common/time.cpp`): 28 hours/day, 1500 ticks/hour, 58 minutes/hour (`minute = (pticks % 1500) / 25`). `time` reply: `It is <m> minute[s] past <h> o'clock <am|pm>, on <weekday>` where shown minute = minute+1, shown hour = `hour % 14` with 0 shown as 14, `pm` when hour ≥ 14.
- Periods: night hour < 5 or ≥ 23; dawn 5–8; morning 8–13; noon 13–15; evening 15–20; dusk 20–23. Sun is up from 5 to 23, highest at 14.
- Sun strength = player-square darkness rule from M1 (unchanged). The clock sets only the light's direction and colour.

## Review Focus

1. **The `time` reply never comes, or comes in another format (other server version).** Expected: sun stays at a fixed morning angle; nothing breaks; no parchment box. Test in Task 2 (`unparseable_reply_gives_none`) and Task 5 (fallback).
2. **The saved monitor or window position is off-screen (monitor unplugged).** Expected: window opens on the main screen. Handled in Task 4 (clamp to a visible monitor); checked by hand.
3. **The settings file has unknown keys, bad values, or MSAA+AO saved by hand.** Expected: defaults for bad values, unknown keys kept harmlessly ignored, combination normalized. Tests in Task 1.
4. **Escape while the parchment box, command box, or inventory is open.** Expected: Escape closes that thing; it does not open settings. Test in Task 3.
5. **Render scale changed while playing, or the window resized.** Expected: the 3D view keeps filling the window at the new scale; the HUD stays sharp. Checked by screenshot in Task 6.

### Task 1: Settings model and file (`settings.rs`)

**Interfaces — Produces:**
- `#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum FrameRate { MatchScreen, Cap30, Cap60, Cap120, Unlimited }`
- `pub enum Quality { Off, Low, Medium, High }` (same derives) — used for AO and shadows.
- `pub enum AntiAlias { Off, Msaa4, Taa }` (same derives).
- `#[derive(Clone, Debug, PartialEq)] pub struct Settings { pub fullscreen: bool, pub window: Option<WindowPlace>, pub render_scale: f32, pub frame_rate: FrameRate, pub ambient_occlusion: Quality, pub shadows: Quality, pub anti_alias: AntiAlias, pub brightness: f32, pub contrast: f32, pub gamma: f32 }`
- `#[derive(Clone, Copy, Debug, PartialEq)] pub struct WindowPlace { pub x: i32, pub y: i32, pub width: u32, pub height: u32 }`
- `impl Default for Settings`: fullscreen false, window None, render_scale 1.0, MatchScreen, AO Medium, shadows Medium, Taa, brightness 0.0, contrast 1.0, gamma 1.0.
- `pub const RENDER_SCALES: [f32; 3] = [0.5, 0.75, 1.0];`
- `impl Settings { pub fn normalized(self) -> Settings; pub fn to_text(&self) -> String; pub fn from_text(text: &str) -> Settings; }` — `normalized`: render_scale snapped to nearest of RENDER_SCALES; brightness clamped −1..1, contrast 0.5..1.5, gamma 0.5..2.0; Msaa4 → Taa when AO ≠ Off.
- `pub fn default_settings_path() -> PathBuf` (Application Support path above; `ponytail:` Mac path, `dirs` in M7), `pub fn load_settings(path:&Path) -> Settings` (normalized), `pub fn save_settings(path:&Path, s:&Settings) -> io::Result<()>` (write temp file then rename).
- Keys: `fullscreen`, `window` (`x,y,w,h`), `render_scale`, `frame_rate` (`match|30|60|120|unlimited`), `ambient_occlusion`/`shadows` (`off|low|medium|high`), `anti_alias` (`off|msaa4|taa`), `brightness`, `contrast`, `gamma`.

### Task 2: Game clock and sun pose (`clock.rs`)

**Interfaces — Produces:**
- `pub fn parse_time_reply(text: &str) -> Option<(u8, u8)>` → (hour 0..27, minute 0..57), per Global Constraints.
- `pub fn is_time_reply(text: &str) -> bool` (starts with `"It is "` and contains `" o'clock "`).
- `#[derive(Default)] pub struct GameClock { synced: Option<(f32, u32)> /* (hour at sync, tick at sync) */, last_tick: u32 }` with `pub fn on_tick(&mut self, tick: u32)`, `pub fn sync(&mut self, hour: u8, minute: u8)` (uses `last_tick`), `pub fn hour(&self) -> Option<f32>` (0.0..28.0, advancing 1/1500 hour per tick, wrapping).
- `#[derive(Debug, PartialEq)] pub struct SunPose { pub elevation: f32 /* radians, ≤0 below horizon */, pub azimuth: f32 /* radians, 0 = east, π = west */, pub moon: bool }`
- `pub fn sun_pose(hour: f32) -> SunPose`: sun up on 5..23: `t = (hour-5)/18`, `elevation = sin(π t) · 70°`, `azimuth = π t`; otherwise `moon: true`, fixed elevation 60°, azimuth π/2.
- `pub const FALLBACK_HOUR: f32 = 10.0;` (morning, used when not synced).

### Task 4: Apply settings (`graphics.rs`)

**Interfaces — Consumes:** `Settings`, `load_settings`, `save_settings`. **Produces:** resource `CurrentSettings(pub Settings)` (loaded at startup), `pub struct GraphicsPlugin`; a system that re-applies whenever `CurrentSettings` changes, and saves it.

Applies:
- Window: `WindowMode::BorderlessFullscreen(MonitorSelection::Current)` vs `Windowed`; `PresentMode::AutoVsync` for MatchScreen, `AutoNoVsync` otherwise.
- Frame cap: a `Last`-schedule system that sleeps the rest of `1/cap` seconds (30/60/120); `ponytail:` sleep-based cap, a pacing crate if it judders.
- Camera (the 3D camera): AO Off → remove `ScreenSpaceAmbientOcclusion`; Low/Medium/High → insert it with the same quality level (Bevy `ScreenSpaceAmbientOcclusionQualityLevel::{Low,Medium,High}`). Anti-alias: Off → `Msaa::Off`, no TAA; Msaa4 → `Msaa::Sample4`; Taa → `Msaa::Off` + `TemporalAntiAliasing`. (Always from `normalized()` settings.)
- Shadows: Off → sun `shadow_maps_enabled: false`; Low/Medium/High → `DirectionalLightShadowMap { size: 1024 / 2048 / 4096 }`.
- Picture: `ColorGrading` on the camera: `global.exposure = brightness`, `shadows/midtones/highlights.contrast = contrast`, `.gamma = gamma`.
- Ambient light: `GlobalAmbientLight.brightness = 600.0` (spec: 4× old value; builder may tune by screenshot).
- Window memory: on start, if `settings.window` is set and lies on a connected monitor, place the window there; else leave default. On `WindowMoved`/`WindowResized` (not in full screen), update `settings.window` and save at most once per second.

- [ ] **Step 1: Implement** (no new pure logic; Task 1 covers the rules).
- [ ] **Step 2: Verify by screenshots** with a hand-edited settings file: (a) defaults; (b) `ambient_occlusion=off`, `shadows=off`; (c) `brightness=0.5`. Expected: visibly different, no crash, no Bevy error in the log.

### Task 5: Sun and moon from the game clock

**Files:** `world.rs`, `main.rs`. **Consumes:** `GameClock`, `sun_pose`, `is_time_reply`, `parse_time_reply`.

- Resource `Clock(GameClock)`, reset in `start_session`. `pump_network`: `Tick(t)` → `on_tick`; a `Text` with `is_time_reply` while a request is pending → `sync`, and the text is **not** pushed to `Msgs` (resource `TimeRequest { asked_at: Option<f32> }`; pending for 10 s).
- On entering `InGame`: send `Ncom "time"` once and set `TimeRequest`.
- `lighting` system: pose = `sun_pose(clock.hour().unwrap_or(FALLBACK_HOUR))`. Sun transform from elevation/azimuth (east = +X, north = −Z). Colour: warm white by day, orange-ish when elevation < 15°, pale blue `moon`. Moon: `shadow_maps_enabled` follows settings only by day; no shadows at night. Strength rule unchanged (player-square darkness).
- Dev override: env `MACCROSSFIRE_HOUR` forces the hour (for screenshots).

### Task 6: Render scale
