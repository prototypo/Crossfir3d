# Which Crossfire picture becomes which 3D visual. Read by crates/maccrossfire/src/models.rs.
# pattern[*] kind args...   (`*` = prefix; exact beats prefix; a full name with its
# frame, like grate_1.118, beats the base name). Unlisted pictures stay picture cards.
#   model <file under assets/models> <scale> <rot_deg> <dy> [r,g,b tint]
#   building <recipe> [SIGN [icon]]   (assembled in code; well, fountain, signpost are
#                       built from shapes; SIGN is shop text, `_` for a space; icons
#                       are named in crates/maccrossfire/src/signs.rs)
#   wall <style>        (joined pieces; styles: stone brick plaster wood hedge rock)
#   flat                (lies on the ground)
#   card                (keep the picture card)
#   statue [r,g,b]      (a half-size stone 3D character on a plinth)
# One map square is 1 unit. Player pictures are handled in code (races.rs).
